# 🚩Capstone Project - "Develop a YouTube Clone Using the MERN Stack "

# Introduction:
           This YouTube clone project demonstrates a strong implementation of core video-sharing platform features using React on the frontend and Node.js with Express on the backend, integrated with MongoDB for persistent data storage. The application emphasizes clean UI/UX, secure user management, and seamless media playback.

# 💥💥💥Features:
       📌User authentication
       📌Video upload and playback
       📌Channels
       📌Comments
       📌Category-based filtering.
       📌Search based filtering
       📌Exclusive UI 
       📌Upload videos into Channel

# 🧰 Technologies Used

| Frontend     | Backend       | Database |
|--------------|---------------|----------|
| React        | Node.js       | MongoDB  |
| React Router | Express.js    | Mongoose |
| Axios        | JWT Auth      |          |
